Scenario

Import a SQLite database

Import opens a .db file from your computer as this tab's app.db, in place of the one the scenario seeded. Your file is read, never written.

Then ask Ptah about it: schema drift compares it with schema.sql, and schema apply --dry-run shows what changing it would take.

A database in WAL mode is refused; checkpoint it first. Reset brings back the seeded database.

The runtime needs JavaScript. Without it this page is still the schema, the file list and the exact commands — they run on your machine instead.

The page below is already yours to read. Only running a command waits for this.

About this playground

Edit a schema, run real Ptah commands against a SQLite database in this tab, inspect the result. Nothing is installed and nothing leaves the browser.

Running
Nothing yet. The build, its commit and the SQLite version appear here once the module in this tab has answered for itself.
Cannot
Reach a network database, run Docker, or touch your disk. There is no PostgreSQL, MySQL or MariaDB here — the driver in this build is SQLite, in memory.
Keeps
Nothing. The workspace and the database live in this tab: reloading discards them. Export takes a copy with you.
